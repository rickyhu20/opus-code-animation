# 提示词的底层逻辑和 7 个要素

先说逻辑。视频模型可以“意会”，代码不行：**代码里的每一个画面、每一种感觉，最后都要变成具体的数字和规则。**

你说“高级一点”，AI 只能猜；你说“米白背景、只用三种颜色、一屏只讲一个卖点”，它就能精确做到。所以好的提示词，就是把脑子里的画面翻译成可以执行的要求。

## 一个完整的提示词，包含 7 个要素

| 要素           | 要说清楚什么           | 例子                             |
|----------------|------------------------|----------------------------------|
| 1\. 做什么     | 主题、时长、画幅、帧率 | 15 秒、1920×1080、30 帧          |
| 2\. 用什么     | 点名工具               | 用 Rough.js / Three.js / Manim   |
| 3\. 长什么样   | 风格、配色、字体、质感 | 米白纸张、黑色铅笔线、少量水彩   |
| 4\. 怎么动     | 按秒写分镜             | 0-3 秒画出树，3-6 秒秋千开始摆   |
| 5\. 不要什么   | 禁用清单               | 不要粒子爆炸、霓虹辉光、夸张弹跳 |
| 6\. 技术硬要求 | 保证能稳定渲染         | 画面只由时间 t 决定              |
| 7\. 怎么交付   | 流程和输出             | 先出分镜、抽帧自检、导出 MP4     |

里面有三个要素最容易被忽略，单独说一下。

**第 5 个，禁用清单。** AI 做的动画为什么容易长得差不多？因为它会默认用最常见的套路：居中大字、渐变背景、所有东西一起淡入。告诉它“不要什么”，模板味会少很多。

**第 6 个，“画面只由时间 t 决定”。** 视频是一帧一帧截出来的，截图的速度和真实播放速度并不一样。如果动画是靠计时器自己跑的，截出来就会跳帧、闪烁。要求“给定一个时间点，画面就是确定的”，渲染出来才稳。

**第 7 个，先出分镜。** 让 AI 停在分镜这一步等你确认，可以避免它写了很久的代码，最后发现方向就不对。

## 可以直接复制的通用结尾

要素 6 和 7 对所有类型都通用，我把它们做成了一段固定结尾。references/types/ 里每种类型的提示词，只要看到“加上通用结尾”，就把这段补在最后：

```text
制作要求：
- 画面只由时间 t 决定，提供 window.seek(t)；不用定时器和 CSS 过渡，随机数用固定种子。
- 用 Playwright 逐帧截图，用 FFmpeg 合成。
- 用 Python numpy 合成配乐和音效，响度标准化到 -14 LUFS。
- 缺少的依赖请自行安装。

流程：
先给我分镜表，我确认后再写代码。
每个镜头抽一帧自检，修掉重叠、看不清的问题。
最后输出 out/final.mp4，并告诉我文件路径。
```

还有三个小技巧：

- **给参考比堆形容词更有用。** 一张参考图、一条参考视频，胜过一堆“高级感”“有质感”。
- **一次只改一个点。** 同时提五条意见，容易改了这里又坏了那里。
- **推理强度调高。** 在 Claude Code 里选 Opus 5.5，effort 调到 high 或以上，细节会明显更好。
