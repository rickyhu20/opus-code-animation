# 12. 数据可视化：D3

**效果：** 折线、柱状图跟着讲解一点点长出来，数字同步滚动，适合财经、趋势类内容。

**工具：** [D3](https://github.com/d3/d3)，最常用的网页数据可视化工具。

**怎么做：** 给真实数据和来源，先定一句核心结论，画面只为这句结论服务。一定要写“不要编造数字”，渲染后也要核对图上的数字。

```text
用 D3 做一条 30 秒、1920×1080、30 帧的动态图表，主题是“一个账号的一年增长”。
数据是虚构示例，片中必须标注“示例数据”：
月份,粉丝数,当月发文数
1,300,4
2,520,4
3,800,6
4,1200,8
5,1500,6
6,2600,8
7,3100,6
8,5200,10
9,6000,8
10,9800,12
11,11500,10
12,16000,12
核心结论：发文量相近的月份，增长也可能相差很大。不要把结论说成因果关系。
分镜：
0-5 秒：标题和坐标轴绘制出来。
5-17 秒：粉丝折线逐月生长，右上角数字同步滚动，下方柱状图显示发文数。
17-23 秒：高亮 6 月和 10 月这两个增长较快的月份，并标注数值。
23-30 秒：折线淡为背景，写出核心结论。
风格：深蓝背景、白色文字、一种青色强调色，不要 3D 效果和多余装饰。
不能修改或编造数据，所有标注由数据计算，渲染后抽帧核对数字。
（加上通用结尾，见 references/prompt-logic.md）
```

用自己的数据时，记得把“示例数据”换成真实来源，并同步修改结论。
