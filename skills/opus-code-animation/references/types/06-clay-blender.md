# 6. 黏土质感：Blender

**效果：** 真实的 3D 黏土小物件，有指纹、柔和光影和桌面景深，像定格动画。

**工具：** [Blender](https://github.com/blender/blender)，免费开源的 3D 软件。再加上 Claude 的 Blender 连接器，或社区版的 [blender-mcp](https://github.com/ahujasid/blender-mcp)，让 Claude 能直接操作 Blender。

**怎么做：** 抖音「卡尔的AI沃茨」教程视频里的分工是搭人物、摆灯、摆镜头，这三步都可以交给 Claude。开始前要先打开 Blender，并启动连接器插件。

```text
用 Blender 做一条 10 秒、1920×1080、24 帧的黏土定格动画，主题是“小海星起床”。
场景：木质书桌，背景是虚化的墨绿色墙面和暖色小灯，桌上有一叠书和一个笔筒。
角色：橙色小海星，圆眼睛，身体由粗细不匀的黏土条组成。
动作：
0-3 秒：海星趴在书上睡觉，轻轻呼吸。
3-6 秒：它睁眼、伸懒腰，身体被压扁再弹回。
6-8 秒：它跳到桌面，落地时稍微压扁。
8-10 秒：转身面向镜头，挥动一只手臂。
材质和灯光：黏土表面有指纹和细小凹凸，窗光来自左侧，光影柔和，开启浅景深。
动作每 2 帧变化一次，做出定格动画的顿挫感。
先渲染 3 张关键帧给我看，并告诉我单帧耗时和预计总时长，我确认后再渲染整段，用 FFmpeg 合成，并保留 .blend 工程文件。
```

注意：这一种上手最难，渲染也最慢，建议放在最后尝试。
