# 11. 粒子片头：Three.js

**效果：** 上万个光点从四周飘来，聚成文字或 Logo，再被风吹散，适合做片头。

**工具：** [Three.js](https://github.com/mrdoob/three.js)。粒子数量少的话，Canvas 2D 也能做。

**怎么做：** 先确定粒子最后要聚成什么形状，再定它们从哪里来、怎么走。记得要求固定随机种子，不然每次渲染的结果都不一样。

```text
用 Three.js 做一条 10 秒、1920×1080、30 帧的粒子片头，文字是“RICKY”（换成你自己的名字）。
风格：纯黑背景，暖金色光点，有景深和柔和发光，但不能过曝。
分镜：
0-3 秒：3 万个光点从四周漂来，像夜里的萤火。
3-6 秒：光点沿弧线汇聚成文字，先聚边缘，再填满。
6-8 秒：文字停留，一道微光从左扫到右。
8-10 秒：一阵风从左吹来，粒子向右散开，画面归黑。
文字先画到离屏 Canvas，采样点作为粒子的目标位置。配上上升音效和文字成形时的低频重音。
（加上通用结尾，见 references/prompt-logic.md）
```
