# 10. 复古质感：WebGL 着色器

**效果：** 老电视的弧形屏幕和扫描线、胶片颗粒、信号干扰、光晕。

**工具：** WebGL 着色器，也是浏览器自带的。着色器可以理解为给画面加“滤镜”的程序，只不过每个像素都由代码精确计算。

**怎么做：** 分两层。先用 Canvas 画内容，再把画面送进着色器加质感。这样内容和质感可以分开调。

```text
做一条 12 秒、1920×1080、30 帧的复古电视短片，主题是“深夜开机”。
做法：先用 Canvas 2D 画内容，再把画面作为纹理送入 WebGL 着色器。
内容分镜：
0-2 秒：黑屏，一条白线从屏幕中央展开，模拟老电视开机。
2-6 秒：像素飞船穿过星空。
6-9 秒：信号干扰，画面错位，出现彩条。
9-12 秒：信号恢复，显示“GOOD NIGHT”，随后画面缩成一个亮点并关闭。
着色器效果：屏幕弧面变形、扫描线、荧光点阵、轻微色差、边缘暗角、光晕、胶片噪点，干扰段再加横向撕裂。文字必须保持可读。
配上电视开机声、电流声和低保真配乐。先给我一张效果预览帧。
（加上通用结尾，见 references/prompt-logic.md）
```
