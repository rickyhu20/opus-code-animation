# 13. 线稿讲解：Python + Pillow

**效果：** 白底黑色线稿，线条带点手绘抖动，轻松有趣，很适合科普和历史。

**工具：** Python 加上画图库 [Pillow](https://github.com/python-pillow/Pillow)。要配音的话，可以接开源的 [Kokoro](https://github.com/hexgrad/kokoro)，或者豆包、智谱这类语音合成接口。

**怎么做：** 给主题或讲解稿，让 AI 按句子切镜头，逐帧画出线稿。这一种不走浏览器，用 Python 直接出图，再用 FFmpeg 合成。

```text
用 Python 和 Pillow 逐帧绘制一条 60 秒、1920×1080、24 帧的线稿讲解动画，主题是“一张图片，怎么从服务器到你的手机”。
风格：白底黑色线稿，线条略带手绘抖动，只用橙色作强调；角色是一个方块小信使，气氛轻松有趣。
分镜和字幕：
0-8 秒：你点开一张猫猫图。（手指点手机，小信使出发）
8-20 秒：请求先到路由器，再一路跑到服务器。（小信使穿过路由器和海底光缆）
20-34 秒：图片太大，会被切成很多小包裹。（猫图被切成小方块）
34-46 秒：小包裹各走各的路，有的还会迟到。（多条路线，一个包裹绕远路）
46-55 秒：手机把它们按顺序拼回去。（方块拼回猫图）
55-60 秒：这一切，通常只要眨眼的工夫。（猫眨眼，收尾）
所有画面用代码绘制，先确认中文字体能正常显示，字幕放在底部、大小适合手机观看。
用 Python numpy 合成轻松的配乐，用 FFmpeg 合成视频。
先给我分镜，我确认后再写代码，每个镜头抽一帧自检，最后告诉我视频路径。
```
