# 5. 板书动画：Manim

**效果：** 公式和图形一步步推导出来，就是很多数学科普视频的那种板书感。

**工具：** [Manim](https://github.com/ManimCommunity/manim)，专门做数学动画的 Python 工具。要显示公式的话，还要装 LaTeX，我用的是轻量版 TinyTeX。

**怎么做：** 先让 AI 写讲解稿，再把每句话对应到一个画面变化。Manim 自己能渲染视频，不需要通用结尾里的截图那一步。

```text
用 Manim 做一条 60 秒、1920×1080、30 帧的讲解动画，主题是“复利为什么这么厉害”。这是通用数学讲解，不是投资建议。
中文用 Text 并指定系统中文字体，公式用 MathTex。
风格：深色背景，白色线条，只用黄色作强调色，一步步板书，不要整段文字直接出现。
分镜：
0-10 秒：标题出现，提问“每年增长 10%，20 年后是多少？”
10-25 秒：写出公式 A = P(1+r)^n，并逐步代入 P=1、r=0.1。
25-40 秒：画坐标轴，同时生长两条线：每年固定加 0.1，和每年乘 1.1。
40-52 秒：标注第 20 年的两个数值，数字由代码计算。
52-60 秒：总结“差距来自：收益本身也在产生收益”。
先用 -pql 低清预览，确认后用 -qh 渲染高清。每段抽一帧检查中文和公式是否正常。
先给我讲解稿和分镜，我确认后再写代码，最后告诉我视频路径。
```
