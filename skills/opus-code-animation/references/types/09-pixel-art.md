# 9. 像素动画：Canvas 2D

**效果：** 16-bit 游戏的质感，像素清晰，动作带一点顿挫。

**工具：** Canvas 2D，浏览器自带。

**怎么做：** 关键是先在很小的画布上画，再整数倍放大，并限制颜色数量。这些规格写清楚，像素感就出来了。

```text
用 Canvas 2D 做一条 15 秒、1920×1080、30 帧的像素动画，主题是“巫师施法”。
技术规格：先画到 160×90 的小画布，再放大 12 倍；关闭图像平滑，坐标取整，不用渐变和抗锯齿；只用 24 种固定颜色；角色动作按每秒 10 个姿势变化。
角色和场景：巫师约 24×32 像素，尖帽子、长胡子、法杖顶端有宝石；夜空、月亮、闪烁的星星和石头地面。
分镜：
0-4 秒：巫师待机，胡子和长袍轻轻摆动。
4-8 秒：举起法杖，宝石闪烁，火花螺旋聚拢。
8-10 秒：释放法球，火花炸开，画面抖动 1 到 2 像素。
10-13 秒：法球飞过天空，点亮一串星星。
13-15 秒：巫师收势，回到待机姿势，首尾衔接成循环。
配上 8-bit 风格的配乐和施法音效。
（加上通用结尾，见 references/prompt-logic.md）
```
