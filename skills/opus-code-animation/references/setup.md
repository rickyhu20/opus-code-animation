# 环境准备、踩坑和局限

## 需要准备什么

| 工具          | 用来做什么                     | 备注                               |
|---------------|--------------------------------|------------------------------------|
| Claude Code   | 让 AI 在你电脑上写代码、跑程序 | 选 Opus 5.5，effort 调到 high      |
| Node.js       | 运行网页动画相关的工具         | 大多数类型都要                     |
| Chrome 浏览器 | 渲染网页画面                   | 或让 AI 装 Playwright 自带的浏览器 |
| FFmpeg        | 把画面和声音合成 MP4           | 所有类型都要                       |
| Python        | 合成音乐、分析节拍、跑 Manim   | 大多数类型都要                     |
| Manim + LaTeX | 板书和公式动画                 | 只有第 5 种要                      |
| Blender       | 黏土和 3D 建模                 | 只有第 6 种要                      |

不知道自己缺什么，可以直接问 Claude：“帮我检查一下这台电脑缺哪些做代码动画的工具，缺的帮我装上。”

## 第一条建议做什么

先从第 9 种像素动画或第 2 种手绘草图开始。它们不用额外素材，不用显卡，出错的概率也最低。每次做一条新的动画，都新建一个空文件夹，在里面打开 Claude Code。

## 我踩过的坑

我在装 Manim 的时候卡了三次，记录下来给大家参考：

1. **粘贴命令时多出了 `[200~`。** 终端报错 `bad pattern`，其实是粘贴时带进了控制字符。解决办法是关掉终端重新打开一个，把命令手动输入一遍。
2. **TinyTeX 的包管理器版本太旧。** 安装公式宏包时提示 `tlmgr itself needs to be updated`，先运行 `tlmgr update --self` 更新就好了。
3. **安装脚本中途报错。** 我的做法是把报错截图原样发回给 Claude，它会自己查原因、改脚本，我再重新运行一次。

总结一句：**遇到报错不用慌，把报错原文交给 AI，比自己上网查快得多。**


## 它不擅长什么，要花多少钱

代码动画很强，但也有明显的短板：

- **不擅长写实画面。** 写实人物和自然风景还是要交给视频模型。
- **要有本地环境。** AI 给的是代码，电脑上要有对应工具才能变成 MP4。
- **有些类型渲染很慢。** 水彩和 Blender 每帧可能要几秒甚至更久。
- **一次成型并不常见。** 很多公开案例都跑了两轮以上，预算和时间按多轮修改来估会更稳。
- **音乐要注意版权。** 用代码合成，或者用你有授权的音乐。

成本差距很大。按公开案例的数据，一句话做出的短片大约 2 美元；几分钟的动画 MV，单次会话可能到 200 美元，或者占掉 Max 套餐 7% 到 10% 的周额度。所以建议先从 10 到 15 秒的短片练手，再慢慢加长。
